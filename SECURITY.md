# Security policy

## Reporting a vulnerability

Report a vulnerability in private, through **Report a vulnerability** on the
[Security tab](https://github.com/linouxis9/oxirush-nas/security) of the
repository. Please do not open a public issue for it.

Say what the input is and what happens: the octets of the message, the
function that was called, and the version or the commit of the crate. A
message that makes a decoder panic, loop or allocate without bound is a
vulnerability, and so is a security context that accepts a message it should
refuse.

## Supported versions

The latest version on crates.io receives the fixes.
